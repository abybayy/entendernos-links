# Enlaces de Lic. Mateo García Moreno

Página de enlaces (bio de Instagram) con la preventa del mazo Entendernos.

- `index.html`: la página. Al inicio del script están `FECHAS` (preventa y venta oficial) y `PAGOS` (links de Mercado Pago).
- Pack x3: cargar la URL en `PAGOS.packX3` para activar el botón.
- Los precios y el encabezado cambian solos por fecha (hora de Montevideo).
